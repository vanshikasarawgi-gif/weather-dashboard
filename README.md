# 🌤️ Weather Dashboard - New Delhi

This project is a **Streamlit-based weather dashboard** that visualizes live weather forecast data for **New Delhi**, fetched from the **OpenWeatherMap API**.

It displays multiple weather parameters such as temperature, humidity, pressure, and sea level, with interactive visualizations created using **Seaborn**, **Matplotlib**, and **Pandas**.

**Live App:** [Click here to view on Streamlit](https://weather-dashboard-delhi.streamlit.app/)
---

## 🚀 Features
- Fetches live weather forecast data using OpenWeatherMap API  
- Displays data in a clean interactive table  
- Visualizes:
  - 🌡️ Temperature vs Time
  - 💧 Temperature & Humidity Trends
  - 🌤️ Min vs Max Temperature
  - 📊 Average Temperature by Hour
  - 🔵 Temperature vs Humidity Scatter Plot
  - 🔥 Correlation Heatmap
  - 🌪️ Pressure Distribution
  - 🔍 Pairplot of Weather Variables
